01 / Idea and design intention

Desktop Beomgyu is a fan-made interface for a small photo-based desktop character inspired by Beomgyu from TXT. The intention is to make a computer feel more playful and companionable. The character can be imagined walking, running, celebrating, and helping carry a file to the Trash.

This coursework translates an existing native Mac prototype into an HTML/CSS dashboard. The page gives the character a clear preview space and places the controls alongside it. The preview is the visual focus; settings are grouped into movement, size, and celebration so a visitor can understand the choices without reading instructions first.

The soft green background and warm white cards create a calm setting. A serif headline adds warmth, while system sans-serif text keeps the controls readable. A responsive two-column layout becomes one column on a smaller screen.

FOOTER: source code and project information
  • header, nav, main, section, aside, and footer describe the page's structure.
  • CSS Grid creates the main preview-and-settings layout. Flexbox aligns smaller groups such as navigation and segmented controls.
  • box-sizing: border-box makes width calculations include padding and borders. Shared spacing, rounded corners, and color variables create consistency.
  • fieldset, legend, and associated labels group real form inputs. CSS :checked and :has() connect those inputs to the preview.
  • CSS keyframes animate the sprite and movement path. The real-photo walk cycle has six generated poses, so it remains a rough prototype rather than fully fluid animation.
  • A media query stacks the layout on narrow screens. Focus outlines and a reduced-motion rule support keyboard and motion-sensitive users.

04 / Intended interactions

Working with HTML/CSS: movement radio buttons switch Stay, Walk, and Run previews; size choices scale the character; the Celebrate mode switches to the chosen happy pose, and Hug plays the 20 original transparent frames directly in the preview. The Trash-helper disclosure expands a storyboard using native HTML details and summary.

Planned beyond this webpage: dropping a file would prompt for confirmation, trigger a run to the Trash, celebrate, and offer Undo. This browser prototype does not access or delete files. Those operations belong to the separate native app, available from the website’s Download section in one complete ZIP that includes the app, character assets, and a quick-start guide. Later iterations added JavaScript for synchronized movement and a new running cycle, and a transparent animated hug made by masking all 20 original GIF frames, preserving the real face after a generated replacement was rejected. The interface structure and styling remain HTML and CSS. ChatGPT integration is an idea that has not been implemented.
